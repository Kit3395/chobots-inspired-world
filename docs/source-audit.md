# Original source audit — initial status

Status: preliminary; no legacy source has been executed.

Reference repository: https://github.com/Chobots/Chobots

Initial observations from its public README and repository metadata:
- The project describes itself as a preservation archive for the original Chobots `.com` game.
- The codebase includes ActionScript-era components and legacy deployment assumptions.
- The README warns of potentially dangerous vulnerabilities.
- The README states that the code has not been relicensed under an open-source or public-domain license.
- Repository metadata reports no recognized license.

Decision:
- Do not copy, execute, compile, or redistribute the archived code as part of this prototype.
- Use the repository for static technical research only.
- Reassess reuse only after license, copyright ownership, asset provenance, and security review.

This is a preliminary engineering record, not legal advice or a complete audit.
